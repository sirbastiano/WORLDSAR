## Overview

WORLDSAR is designed as a Geospatial Foundation Model (GFM) workflow for Synthetic Aperture Radar (SAR) products.  
It supports consistent preprocessing, orchestration, and data extraction across missions and acquisition modes.

## Project Focus

- Multi-mission SAR support (for example Sentinel-1, BIOMASS, NISAR, TerraSAR-X, CSG)
- Multi-mode processing across swath, stripmap, and related SAR acquisition configurations
- Reproducible local and cluster execution through unified `Makefile` and script flows
