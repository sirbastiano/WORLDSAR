4. Input Product

Put your .SAFE product under ./phidown_data, or download with:

make down PRODUCT=<product_name>.SAFE

PRODUCT for make run and make run-vm can be:

  • The .SAFE directory name
  • A full path to that .SAFE directory

main.sh normalizes to the basename and resolves under ./phidown_data.

5. Running

Default mode: WORLDSAR_MODE=vm.

5.1 Local VM Run (No PBS)

make run-vm PRODUCT=<product_name>.SAFE

Example:

make run-vm PRODUCT=./phidown_data/S1A_S3_SLC__1SDV_20151229T152825_20151229T152844_009258_00D5C6_F1C9.SAFE

5.2 Cluster Run (PBS/qsub)

WORLDSAR_MODE=hpc make run PRODUCT=<product_name_or_full_path>.SAFE

Equivalent behavior is achieved by setting WORLDSAR_MODE=hpc so the Makefile uses HPC defaults for paths and scheduler options.

In PBS mode, PRODUCT is injected through qsub environment variables (-v PRODUCT=...), so qsub does not receive positional script arguments.

For your workflow, HPC hardcoded defaults are also defined near the top of main.sh (for example HPC_BASE_DIR and related paths).

Set Makefile mode defaults in Makefile (top section): WORLDSAR_MODE, VM_PROJECT_ROOT, HPC_PROJECT_ROOT; use command-line overrides for one-off runs.

Execution Choice Guidance

Use run-vm first for validation and troubleshooting in your current shell session.

Use run when your environment is PBS-enabled and you need queue-based execution.
