Router Mapping

Mission mode dispatch configured in ROUTER:

  • S1TOPS -> pipeline_sentinel(is_TOPS=True)
  • S1STRIP -> pipeline_sentinel(is_TOPS=False)
  • TSX -> pipeline_tsx_csg
  • CSG -> pipeline_tsx_csg
  • BM -> pipeline_biomass
  • NISAR -> pipeline_nisar

Sentinel-1 TOPS (S1TOPS)

Splits by IW swath and applies orbit, calibration, deramp/demod, deburst, polarimetric decomposition, and terrain correction per swath.

Sentinel-1 STRIP (S1STRIP)

Runs orbit correction, calibration, subaperture step, polarimetric decomposition, and terrain correction.

TerraSAR-X (TSX)

Runs calibration then terrain correction at 5 m spacing.

COSMO-SkyMed (CSG)

Uses the same preprocessing function as TSX: calibration then terrain correction at 5 m spacing.

BIOMASS (BM)

Writes product output using the GeoTIFF writer pipeline.

NISAR

Validates .h5 format and passes the product through preprocessing; tiling is handled downstream by NISARCutter.
