6. Monitoring and Logs

Cluster mode monitoring commands:

make status
make logs

In local VM mode, logs are written as timestamped files to ./logs with .stdout.log and .stderr.log suffixes.

7. Useful Cleanup

make clean
make clean-logs
make clean-snap-artifacts

make clean-snap-artifacts removes temporary SNAP download/extract files under ./.tmp/snap.

Cleanup Strategy

Use clean to reset outputs before a fresh processing run.

Use clean-logs to reduce log noise without touching generated data products.

Use clean-snap-artifacts after SNAP bootstrap when temporary files are no longer needed.
