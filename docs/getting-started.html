1. Prerequisites

  • Linux environment with bash
  • apptainer (or compatible Singularity runtime)
  • hf CLI (Hugging Face CLI)
  • curl
  • For cluster mode only: qsub/PBS commands available

2. Repository Setup

From repository root, run:

cd WORLDSAR

Optional Python environment setup:

uv sync

Setup Intent

uv sync is optional for Makefile-driven runtime commands, but useful when you need local Python tooling in this repo. Core processing is containerized via the SIF runtime and SNAP userdir.
