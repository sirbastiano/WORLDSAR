Repository Mental Model

WORLDSAR orchestration is centered around a small set of components. Learn these first:

1. Orchestration Layer

Makefile gives stable commands. main.sh performs the real run logic called by make run and make run-vm.

2. Runtime Dependencies

sarpyx.sif and .snap are required runtime assets. The Makefile can bootstrap both automatically.

3. Data Flow

Input products live in ./phidown_data. Outputs are generated under ./OUT (output, tiles, DB).

4. Execution Modes

Use run-vm for local execution. Use run for PBS cluster submission with qsub.

Quick Start (Relative Paths Only)

  1. Enter the repository root directory.
  2. Prepare runtime assets (sarpyx.sif, .snap).
  3. Place or download a .SAFE product.
  4. Run with local VM mode first.
  5. Use monitoring and cleanup commands as needed.
cd WORLDSAR
make pull-sif
make pull-snap
make down PRODUCT=<product_name>.SAFE
make run-vm PRODUCT=<product_name>.SAFE
